# 开发与调试记录

本文件补充 [开发对话](conversation.md)，按任务阶段记录关键执行与验证。公开副本省略主机路径、账号和认证信息，课程课件保留在本机。

1. 根据课程要求确立目录输入、动态执行、崩溃报告、开源交付的验收项。比较自制事务工具与现成 jq，确定用现成 jq 作为实验目标。
2. 核对 jq 上游 issue #3348 和修复 PR #3350。官方文件下载发生中断后完成续传，分别按发布 API 提供的 SHA-256 核验 1.8.0、1.8.1。公开案例先用于版本自检。
3. 实现目标清单、独立进程、退出分类、字节和结构化变异、故障去重、同签名缩减及重放。Windows 上识别断言与原生异常退出，保留退出状态和错误输出。
4. 用正常脚本运行固定种子实验。种子 7 的试跑在第 6 次执行捕获断言。随后生成真实终端运行录像，同时保留输出事件的时间线。
5. 比较三组随机种子下的字节级与结构化变异。另测 JSON 边界和排序性质。保存每次运行摘要和确认结果。
6. 校验发布包结构、录像编码和可重放结果，准备提交指南。Linux Clang 插桩属于提供的扩展，Windows 官方二进制实验未采集边覆盖。
