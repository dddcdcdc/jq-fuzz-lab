# 演示录像

[播放 MP4](demo.mp4)

本文件是**桌面实际屏幕录像**：由 ffmpeg 的 gdigrab 采集录制期间的真实桌面，画面来自当时运行的控制台窗口，不是事后重绘的动画。录像录制于 2026-11-09，分为三段连续镜头，因为录制环境的控制台窗口在输出超过可见行数后会停止刷新，分段可以保证每段都完整显示。

三段内容依次为：

1. 平台自检 23 项通过；用例库 269 条（每版 263 条）在 jq 1.8.0、1.8.1 上各 263/263 通过。
2. 从 5 个正常脚本开始的一次 100 次执行的结构化变异，第 6 次执行捕获断言，反例从 52 字节缩减到 2 字节，并显示缩减后的输入。
3. 同一输入在 jq 1.8.0 上重放仍触发崩溃，在 1.8.1 上被正常拒绝；两版比较为 257 条共有、0 处差异、缺失 0、新增 0、版本专属 12。

为控制节奏，命令是预先写入批处理按顺序执行的，窗口中的命令回显由脚本打印；**所有输出均为命令真实执行结果**，产物写入 `results/`。机器可读结果见 [results/demo](../results/demo/)、[results/suite](../results/suite/) 和 [实验报告](../results/report.md)。
